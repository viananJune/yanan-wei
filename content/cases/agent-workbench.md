## Problem

例程如果只存在于某一次对话里，第二天就接不上。报告只有一种语言时，复查或转发都要重写一遍。文件若到不了自己的 Windows 机器上，工作台隔夜就断了。

## Approach

重复事项写成可以再次运行的例程。报告保留中文正文，并带上短英文标签，方便自己索引。同步按 Windows 上已经在用的目录和节奏来，让同一份结果第二天还在本机。

## Outcome

例程可以按同一方式再跑。报告中英对照。文件落在 Windows 上对得上的位置，第二天接着用。工作台服务的是自己的一天。

## Stack

- 可重复运行的例程
- 中文正文与英文短标签
- Windows 路径上的同步约定
